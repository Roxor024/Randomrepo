# Behind It All — Shared Production Workspace

A cinematic storytelling channel explaining the people, inventions, companies, history and events behind the headlines.

## Pilot episodes
- **E001 Harry Kane** — emotional first-love-to-Ballon-d'Or Instagram Reel (script under revision)
- **E002 Anthropic / Claude** — origin of Anthropic and how Claude was built
- **E003 Ancient Egyptian pyramids** — immersive historical engineering story

## Collaboration
- **ChatGPT:** creative direction, story research, fact review, script and finished-cut review.
- **Claude:** narration production, storyboard, visual assembly, editing and exports using tools available in Claude.
- **Owner:** approves narration credits, any paid operations, licensed assets and publishing.

GitHub is the shared source of truth. It does **not** make the two conversations automatically message or trigger each other.

### Rules
1. Do not spend credits or invoke paid APIs without explicit approval.
2. Commit approved scripts and storyboards; mark drafts clearly.
3. Keep licensed footage/audio, private credentials and API keys out of this public repository.
4. Do not claim that production assets exist until verified.
5. Note sources and distinguish dramatization from documented facts.
